# Parblo Coast 13 OpenTabletDriver Plugin

OpenTabletDriver plugin for the **Parblo Coast 13** graphics tablet.

This plugin was developed through reverse engineering of the tablet's USB HID reports and is intended to provide support for the device on Linux through OpenTabletDriver.

## Features

* Pen position
* Pressure sensitivity
* Pen buttons
* Eraser
* Pen proximity detection
* Tablet area mapping through OpenTabletDriver

## Device

| Property       | Value           |
| -------------- | --------------- |
| Device         | Parblo Coast 13 |
| USB Vendor ID  | `0x0B57`        |
| USB Product ID | `0x9020`        |
| Interface      | USB HID         |

## Installation

Install [OpenTabletDriver](https://github.com/OpenTabletDriver/OpenTabletDriver), then install this plugin according to the OpenTabletDriver plugin installation instructions.

After installation, select **Parblo Coast 13** as your tablet device.

## Known Limitations

This plugin was developed using the hardware available to me, so some features could not be fully verified.

### Pressure range

My pen was **purchased separately from the tablet** rather than being the original pen bundled with the Coast 13.

Because of this, the pressure range reported by my pen may differ from the pressure range of the original Parblo pen. If pressure does not reach the expected maximum value on your device, this may be the reason.

If you have the original pen, feedback about its pressure range would be useful.

### Tilt

I was **unable to find Tilt X/Y data** while reverse engineering the HID reports.

Tilt support is therefore currently **not implemented**.

This does not necessarily mean that the hardware does not support tilt — only that I could not identify a corresponding value in the reports available to me.

### Tablet wheel

I was also unable to identify where the **tablet's physical wheel** is represented in the HID reports.

The wheel is therefore currently **not supported**.

## Reverse Engineering

The plugin was created by capturing and analysing the USB HID reports generated by the tablet and pen.

Several report types were identified, including:

* Pen position and pressure data
* Button states
* Pen proximity
* Tool switching / eraser state
* Device reset / overflow reports

The protocol is not officially documented by the manufacturer.

If you have a different revision of the Parblo Coast 13, a different bundled pen, or information about the wheel or tilt reports, additional HID captures would be very useful for improving support.
